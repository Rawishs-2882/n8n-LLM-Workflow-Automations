# n8n-LLM-Workflow-Automations

Intelligent automation workflows built in n8n, connecting OpenAI APIs with Gmail, Google Sheets, and Airtable for AI-assisted data processing and notifications.

## Features
- OpenAI API integration for AI-assisted processing
- Gmail, Google Sheets, and Airtable automations
- Exportable n8n workflow JSON files for reuse

## Tech Stack
n8n, OpenAI API, Gmail API, Google Sheets API, Airtable API

## Setup & Run
1. Import the workflow JSON files from `/workflows` into your n8n instance.
2. Configure credentials for OpenAI, Gmail, Sheets, and Airtable in n8n.
3. Activate the workflow.
